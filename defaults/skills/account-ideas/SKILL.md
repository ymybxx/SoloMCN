# 选题雷达：给账号出题

参数在调用时给出，格式是：`精选 id：<id>；账号：<代号>、<代号>；每个账号 <n> 个`。缺参数就停下说明，不要猜。

参数后面可能还有一行「这次的方向」（用户写的一句话，比如「要参加抖音 vibe知识大赏 征稿」）：出题按它来。方向里有征稿、活动的，先弄清它的要求（内容方向、必带话题、标题前缀、截止，可以用 `douyin_topics` 查），每条选题都要能按要求做，`title` 照要求的格式写（比如要求的标题前缀），`whyNow` 写上征稿和截止。

工具来自项目的 `workbench` MCP 服务。如果工具报“连不上工作台服务”，直接停下并说明原因。

## 流程

### 1. 读材料

并行调用：

- `get_picks`，传 `id`：这个精选的主题、依据的素材、建议方向和风险
- `get_accounts`：账号的人群、人设、风格、主打情绪和系列（`series`：这个账号几类做法不同的视频，`topics` 是系列适合的题材）
- `get_recent_context`：雷达里还没处理的选题和最近的内容，**不要出重复或高度相似的题**；`topPerformers` 里表现好的情绪和形式可以多用

精选的素材信息不够时（比如素材讲的工具你不了解），用网页搜索查清楚再出题，不要凭标题猜。打开原文时注意：

- **推特链接**（`x.com/.../status/...`）不要用 WebFetch 打开，会返回 402。用 `x_user_tweets` 读链接里那个用户最近的推文找到原推，翻不到就用 `x_search` 搜 `from:用户名 关键词`
- **课程、论文类素材**优先读网页版的主页、政策页、作业页；PDF 讲义用 WebFetch 通常只拿到二进制，读不出正文，不要指望从里面摘数字

**精选里有 YouTube 视频的**，每一条都先用 `get_teardown` 读拆解报告；还没拆过的，按 `/teardown-video` 技能的做法拆（读字幕、简介、热门评论，写报告，`save_teardown` 存到视频上），再出题。几个账号共用同一份拆解，不要每个账号拆一遍。

用拆解出题时：借它的选题、观众在意的点和讲法，**出的是我们自己的原创选题**：按账号人设换人群、换角度，优先做报告里「我们可以怎么做得不一样」和评论区追问的点。不要出「把这条视频翻译/重做一遍」这种题。选题的 `why` 里写上参考了哪条视频。

### 2. 转化：主题 → 账号选题

对每个账号，先问“这个账号的人群在这件事上有什么情绪”，再按系列的做法放大。**先定系列。** 账号有系列（`get_accounts` 的 `series`）时，每条选题先决定归到哪个系列，再按那个系列的定位、固定结构和适合的题材来设计；同一个主题可以给同一账号的不同系列各出一条，角度要按系列的做法变。写入时 `series` 填系列名。同一个主题给不同账号，**角度必须真的不同**，不是一个题换个皮。手法按账号的做法挑，下面是常用的几种，不是每个账号都适用：

| 手法 | 例子 |
|---|---|
| **角色代入**：让账号固定的角色经历这件事 | 返程高峰 → 打工动物堵在高速上开视频会 |
| **荒诞放大**：把情绪推到极致 | “来不及写作业” → 古代书童连夜帮皇帝补奏折 |
| **时空反差**：放到古代、未来或动物世界 | 国庆返程 → 1990 年的绿皮火车春运 |
| **情绪共鸣**：只取情绪，不提事件 | “下次回来就是 2027 年了” → 离家时爸妈站在路口的背影 |
| **新玩法演示**：海外刚火的新玩法、新工具，直接做出来给国内观众看 | 海外刚火的一种转场剪法 → 用同样的剪法做一条账号自己的内容 |

每条选题按这几个按钮检查：

- **前 3 秒**：`hook` 的第一句台词先说出主题，再接违和感或好奇缺口。标准按 write-script 第 4 步的开头检查：看完第一句能复述出「这条讲的是 XX」，只有场景、道具不算；不合格就改写 `hook`
- 命中哪种**高唤醒情绪**：感动、好笑、震惊、爽感、怀旧、治愈
- 目标人群会不会觉得**“说的就是我”**
- 转发出去，转发的人**显得怎么样**（有趣、有共鸣、有品位）

### 3. 打分

四项各 1–5 分，**如实打**，大部分应该在 2–4 分：`hook` 前 3 秒抓人程度、`emotion` 情绪强度、`relate` 目标人群代入感、`social` 转发欲望。

总分低于 11 分的不要写入。某个账号凑不够数，宁可少出，在汇报里说明原因。

### 4. 写入

调用 `add_ideas` 一次性写入。每条都要：

- `pickId` 填这个精选的 id（工作台靠它把选题和精选关联起来）
- `account` 用账号代号
- `series` 填归到的系列名（账号有系列时必填）
- `trend` 填依据的素材（原标题和渠道），`whyNow` 写为什么现在做
- `risk` 只写事实层面要核实的地方和平台审核可能敏感的地方，一两句话，供人参考；不写“不点名”“不展示截图”这类创作限制。确实没有就写空字符串

### 5. 汇报

**用中文写**。几行话：每个账号出了几条，最推荐哪一条、为什么（提到分数时照抄写入的总分）；没凑够数的说明原因。不要把选题全部重复一遍，它们都在工作台的「账号选题」里。

## 红线

**唯一的红线：不伪造。** 不编造新闻、事件、测试结果和数据；不合成真人的脸或声音，让他说没说过的话、做没做过的事。除此之外不设限制：可以点名真实的公司、产品、开源项目、博主和公众人物，可以用他们公开的网页、帖子截图和官方视频片段做介绍和评论（出处记在后台）。
