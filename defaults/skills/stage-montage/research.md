# 原片剪辑：调研

选题要用真实视频画面的（偶像舞台、演唱会直拍、综艺名场面、游戏实况、体育、影视片段），就从 B站找片段：

1. **搜**：`bilibili_search`，换几种说法搜（人名 + 歌名 + 直拍 / 纯享 / 官摄 / 4K / 场次名），按播放量（`click`）和综合（`totalrank`）各看一遍，把同一首歌、同一个节目的不同场次都找出来。标题里写着「混剪」「换装」的成品剪辑可以参考它的节奏和选段；当素材时优先用原始直拍和官方视频（成品剪辑内部已经有切点和换场，再剪容易乱）。
2. **看详情**：对候选用 `bilibili_video`。`size` 看原始分辨率和横竖屏，成片是横屏就挑横屏素材，竖屏就挑竖屏素材，原始分辨率低于 1080 的少用。一般舞台混剪优先：官方账号的纯享、官摄 > 单场单人直拍 > 多天混剪的直拍；做一键换装时按第 6 条，只要单机位单人直拍。
3. **看画面**：`bilibili_preview` 不用下载就能看整条视频的缩略图拼图（带时间码），用读文件工具打开，确认场次、造型、主角在不在画面中间，再决定下不下。
4. **挑段落**：`bilibili_highlights` 看弹幕最密的几段（高音、炸场动作、名场面），记下时间，写脚本时用来安排停留。
5. **剪下来**：`capture_bilibili` 存成素材，`note` 写清楚：是谁、哪首歌或哪个节目、哪一场（日期、场次名）、造型（发色、衣服颜色和款式）、横屏还是竖屏、单人还是多人。返回里提示没登录（480P）的，在汇报里提醒用户去「渠道 → B站热门视频」扫码登录后重新调研，480P 放进成片会糊。
6. **一键换装 / 同曲多场混剪**（成片要做到「从头到尾像一个人、只换了衣服」，素材决定能不能贴合）另外要满足：
   - **只要单机位直拍**：标题、简介里写着「多机位」「三机位」「精剪」「混剪」的不要（里面已经剪过、有大量特写，没法对齐）；官方纯享、官摄多半是导播切换的多机位，也只当音轨或参考。
   - **他在画面中间、景别稳**：中景到中远景（膝盖以上入画），镜头一直跟着他；全场远景、大特写、推拉很多的不要。下载前先用 `bilibili_preview` 看拼图确认。
   - **机位角度接近**：优先正面、高度差不多的座位拍的；正面和侧面的两条动作再像也贴不上。
   - **少遮挡**：摄影师、队友经常挡在他前面的不要。
   - **横屏、原片 4K 优先**（放大对齐时更清楚），整首连续、中间没有剪辑（才能和主音轨对齐）。
   - **每套造型找 2 条候选**（同一场、不同座位拍的），都整首下载；6–10 套造型差别明显（日期、发色、服装），同一套造型的两条在 `note` 里写同一个造型标签，格式「造型：0726 白发球衣」，做视频时按它分组（同一套的两条之间切换不算换装）。
   - **下载后逐条体检**：`vet_footage`（item_id、asset_id 来自 `get_item` 的 assets），看分数和原因。每套造型留分最高的一两条；「不适合」的（多机位、景别忽远忽近、他总在边上、经常被挡）体检结果会存在素材上，做视频时自动不用；报告里写明，并找替代素材再下、再体检。一套造型找不到 55 分以上的，在报告里说清楚，这套可以不用。
   - 再下一条**音质最干净**的同曲版本当主音轨：官方 MV、舞蹈版 MV、官方纯享或录音室音源，`note` 里写「主音轨候选」。官方 MV 多是群舞镜头、主角不一定在画面里，一般只用它的声音。
7. 片段之间的音轨对齐、踩拍、渲染都是生成视频那一步的事（见 `video.md`），调研时不用写对齐脚本、不用拿合成音频做实验。
8. 报告里加一节【素材清单】：每条片段一行（造型标签、场次、横竖屏、画质、UP 主、体检分数和原因、可以重点用的时间段），主音轨标出来。
