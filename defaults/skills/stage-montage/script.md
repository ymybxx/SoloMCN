# 原片剪辑：写脚本

写的是**剪辑方案**，不是解说稿：画面全是真实片段，声音是歌曲原声，**默认没有旁白和配音**。格式换成：

```
【标题备选】3 个，每个 20 字以内（人名 + 歌名 + 形式，带一个钩子，如「别眨眼」「N 套造型无缝切换」）
【封面文案】
【时长】按系列时长，不超过歌曲本身
【剪辑方案】
形式：一键换装 / 舞台混剪
画幅：横屏 1920×1080 或竖屏 1080×1920（跟着素材的横竖屏走，素材多数是横屏就做横屏）
主音轨：用哪条素材的声音（素材 note 里写了「主音轨候选」的那条），从歌曲哪里到哪里（前奏、某句歌词、结尾），超出系列时长时砍哪一段
素材：每条一行：代号｜场次和造型｜画面上的场次小字（10 字以内，如「0726 梦寐以求」）｜用不用、为什么
节奏：基础每几拍切一次；哪几段加快（副歌、鼓点密集处每 2 拍）、哪几段停住不切（高音、名场面、定格动作，写明用哪一场）
顺序原则：造型反差大的接在一起（黑白、红白交替），同一场不连续出现
【段落】每段一行：段落（前奏 / 主歌 / 预副歌 / 副歌 / 舞蹈 break / 结尾，带歌词开头）｜切换节奏｜重点画面（用哪几场、停在哪个动作）｜屏上字（没有就写无）
【片头片尾字】开头 2–3 秒的标题字、结尾定格字，没有就写无
【结尾互动】一句引导评论的话（只放在发布文案里，不进画面）
【平台差异】
```

- 场次、日期、造型只能来自素材的 `note` 和调研报告，不要编。
- 屏上字少而短，不挡人；整首不加旁白，除非系列明确要求。
- 弹幕高能时刻（调研报告的【素材清单】）是停留镜头的首选。
