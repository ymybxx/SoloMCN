# 原片剪辑：一键换装、舞台混剪

画面全是调研时从 B站剪下的真实片段（多数是整首直拍），声音是一条主音轨的歌曲原声。各片段按音轨对齐、踩着拍子切换：同一个动作接着跳，造型一下变了，这就是「一键换装」。音乐必须完整，不为画面剪歌。

各环节看这里的哪个文件：

| 环节 | 文件 |
|---|---|
| 调研：找素材、挑素材、体检 | `research.md` |
| 写脚本：剪辑方案的格式 | `script.md` |
| 生成视频：对齐、排切点、贴合换装、渲染、审片 | `video.md` |
| 修改视频：按意见改切点、构图、水印 | `revise.md` |

程序都在 `scripts/`：`montage.mjs` 是总入口（对齐、排切点、渲染、体检都是它的子命令），`pose.swift`、`lockfx.swift`、`array.swift`、`persons.swift` 由它调用。
