# 发布前预审

参数里有 `内容 id`。工具来自项目的 `workbench` MCP 服务。预审只给参考意见，**不替人勾审核清单**。

## 流程

1. 调用 `get_item` 读内容、脚本和账号人设。脚本是空的就说明并停下。
2. 脚本里提到真实事件、热点、品牌或具体人物，而你拿不准它们是否真实、是否敏感时，用网页搜索核实一下。
3. 逐项判断，每项给出通过与否和一句理由：

| key | 判断什么 | 什么算通过 |
|---|---|---|
| `notMisleading` | 观众会不会误以为是真实事件、新闻或监控画面 | 不会 |
| `noRealPerson` | 有没有用 AI 伪造真人的脸或声音，让他说没说过的话（点名、展示公开截图不算） | 没有 |
| `hook` | 前 3 秒有没有违和感或好奇缺口 | 有 |
| `emotion` | 有没有明确的高唤醒情绪（感动、好笑、震惊、爽） | 有 |

4. 写一句最重要的修改建议。
5. 调用 `save_precheck` 保存，然后用一句话汇报结论。

判断针对作品内容本身。缺少 AI 标识、虚构/示意/非实测说明、安全提示或免责声明不能导致不通过，也不建议补加到脚本或视频。发现事实依据不足时，建议删除无依据断言或换成有依据的内容；资料缺口和审阅意见只保留在预审结果中，不变成台词、字幕或角标。
