# 数据复盘

工具来自项目的 `workbench` MCP 服务。

## 流程

1. 调用 `get_published` 读所有已发布内容的数据和账号人设。没有已发布内容就说明并停下。
2. 想给下周选题方向时，可以调用 `get_hot_topics` 看看当前热点，让建议贴近现在的时机。
3. 写复盘，调用 `save_analysis` 保存全文。
4. 用两三句话汇报最重要的结论。不要把全文在回复里再贴一遍。

## 复盘格式

纯文本，不要用 Markdown 符号，按这些小标题：

```
【一句话结论】
【赢在哪里】哪个系列、哪类选题、情绪、形式表现最好，用数据说话（`published` 里的 `series` 是所属系列，同一账号的几个系列要分开比）
【问题】表现差的原因推测
【各账号建议】每个账号一两句：加码、调整还是暂停
【下周选题方向】5 个具体方向，标明给哪个账号
```

## 要求

- 用中文，简洁直接，不要客套
- 每个结论都要能对上数据；样本少的时候明确说结论不可靠
- 下周方向要符合账号人设；唯一的红线是不伪造（不编造新闻、事件、测试结果和数据，不用 AI 合成真人的脸或声音）
